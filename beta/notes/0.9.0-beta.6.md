## Glint 0.9.0-beta.6: in-game updates

**New**
- **Updates install from inside the game.** At startup Glint checks for a new version. If there is one, *Update now* downloads only the files that changed (usually a few MB), restarts the game and you're on the new version. No installer needed.
- *Options → Check for updates* checks by hand.

This is the last time you need the installer for an update. Your progress and settings are kept.
