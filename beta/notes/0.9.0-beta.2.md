## What's new in 0.9.0-beta.2

- **Windows installer.** A branded setup wizard installs the game for your user account (no admin needed). It adds Start menu and desktop shortcuts, plus an uninstaller in Windows "Apps". The portable zip is still available.
- Release builds are now published automatically with both the installer and the zip.

Upgrading from beta.1? Just run the new installer. Your progress and settings are kept.
